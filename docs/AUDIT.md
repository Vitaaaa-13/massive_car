# Технический аудит

| Критичность | Дефект исходного прототипа | Причина и компонент | Исправление |
|---|---|---|---|
| Критическая | При смене схемы удалялась таблица `chunks` | `app.py:init_db`, `DROP TABLE` без копии | Новая схема создаётся рядом без удаления старых данных |
| Высокая | Ответы и ссылки на пункты были прописаны вручную | `generate_response`, нельзя проверить существование ссылок | Поиск по активным редакциям, запрос к GigaChat, проверка ID процитированных фрагментов |
| Высокая | Ключ GigaChat и сетевые ошибки не обрабатывались | Реального клиента не было | OAuth, таймауты, повторы, сообщение об ошибке; ключ только в окружении |
| Высокая | Поиск `LIKE` без ранжирования | `search_db` | SQLite FTS5 с BM25 и нормализацией русских окончаний; семантический поиск пока отсутствует |
| Высокая | DOCX создавался с нуля для одного типа | `create_docx` | Генерация из семи оригинальных модулей, удаление блока пояснений, сохранение таблиц и служебных зон |
| Высокая | Редакции не хранились | Одна таблица фрагментов без идентичности исходника | `documents`, `revisions`, `fragments`, атомарное переключение активной редакции |
| Средняя | Небезопасный HTML с вводом пользователя | `unsafe_allow_html` и вставка текста сообщений | Сообщения показываются стандартным Streamlit markdown |
| Средняя | Не было защиты административных действий | Все действия без роли | Вход по PBKDF2-хешу, серверные условия в обработчиках Streamlit |
| Средняя | Интерфейс с тяжёлыми градиентами и без темы | CSS прототипа | Спокойная светлая и тёмная палитры, системная тема |

Незакрытые риски: отсутствуют локальные multilingual embeddings, часть полей семи модулей требует ручной проверки готового текста, нет полноценной проверки черновика на соответствие матрице, нет отдельного HTTP API для разграничения прав вне Streamlit.
