# Прогресс

Реализованы новая схема без разрушения старой БД, сохранение редакций, PDF/DOCX-парсинг, FTS5, клиент GigaChat, проверка существования источников, маршруты по двум типам матрицы, генерация из семи модулей, базовая проверка черновика, интерфейс и Docker-конфигурация.

Остаётся: семантические embeddings и гибридное ранжирование, полноценное диалоговое заполнение и изменение полей, точная модель всех зависимостей семи модулей, глубокая проверка черновиков и полные браузерные сценарии. Сохранение данных после пересоздания контейнера проверено. Детали фактической проверки находятся в `docs/demo/TEST_REPORT.md`.
