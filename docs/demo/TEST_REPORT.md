# Отчёт о проверке

Дата: 25 октября 2026 года.

## Выполнено

- `docker compose up --build -d` — успешно; контейнер получил статус `healthy`.
- `docker compose run --rm app pytest -q` — 16 тестов прошли.
- `AppTest.from_file('app.py').run()` — исключений нет.
- Реальный OAuth GigaChat — токен получен, список моделей прочитан. Запрос к `GigaChat-3-Lightning` вернул ответ `Привет.`. Имя модели `GigaChat` дало 404, поэтому заменено.
- Реальный вопрос по рабочей группе для ИТ-проекта — получен маршрут с ДОУ, кадровым подразделением и ИТ, с ID фрагмента активной матрицы.
- Реальный общий RAG-запрос о регистрации входящих документов — GigaChat вернул ответ с двумя существующими фрагментами инструкции.
- В браузере открыты чат и каталог шаблонов, проверены ответ с источником, семь пунктов каталога, тёмная и светлая темы. После исправления светлая тема имеет читаемые поля и кнопки.
- После пересоздания контейнера сохранились 10 документов, 10 редакций и диалоговые сессии. Исходная таблица `chunks` содержит 303 записи, новый индекс — 584 фрагмента.
- Оригинальная БД скопирована в `data/backups/docassist-before-2.0.db` перед изменениями. Файл резервной копии исключён из Git и образа.

## Пределы проверки

Проверки DOCX подтверждают открытие всех семи файлов, сохранение количества таблиц и блока ЭП, удаление блока пояснений и валидацию обязательных полей. Полная визуальная сверка каждого модуля с оригиналом и все варианты необязательных пунктов не выполнены. Семантический retrieval, глубокий анализ черновиков, диалоговое заполнение шаблонов и корпоративная ролевая модель не реализованы. Защита реальных банковских данных не оценивалась.
