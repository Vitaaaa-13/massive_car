# Покрытие требований кейса

| Требование | Статус |
|---|---|
| Вопросы по загруженным документам с источниками | Реализовано частично: FTS5 и проверка ID, без семантического поиска |
| Актуальные редакции и история | Реализовано; требуется регрессионная проверка Docker-перезапуска |
| Маршрут визирования | Реализовано частично: рабочая группа и приказ о вводе ИС |
| Семь оригинальных модулей DOCX | Реализовано частично: базовое заполнение; ручная проверка всех вариантов обязательна |
| Диалоговое создание черновика | Не реализовано |
| Проверка черновика | Реализовано частично: незаполненные поля и служебные пояснения |
| Светлая, тёмная и системная тема | Реализовано частично: выбор сохраняется в URL, но не в профиле пользователя |
| Административный доступ | Реализовано частично: локальный пароль, без корпоративной IAM |
| Docker Compose | Реализовано; результаты запуска в `TEST_REPORT.md` |
