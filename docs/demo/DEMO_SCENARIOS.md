# Сценарии демонстрации

1. Открыть «Документы» и показать активную редакцию инструкции и строки матрицы. Проверено автоматическим тестом редакций и запуском интерфейса.
2. В чате спросить о визировании рабочей группы для ИТ-проекта: ДОУ, кадры и ИТ с объяснением условия. Проверено тестом и вручную в браузере.
3. Спросить о рабочей группе без ИТ-компонента: ИТ-подразделение не добавляется автоматически. Проверено тестом.
4. Спросить о приказе о вводе ИС: юридическое подразделение, ДОУ, информационная безопасность и ИТ. Проверено тестом.
5. В «Шаблоны» заполнить поля распоряжения о рабочей группе и скачать DOCX, сохранив постоянные пункты и блок электронной подписи. Генерация проверена автоматическим тестом; скачивание в браузере ещё не проверялось.

Для демонстрации ответа GigaChat предварительно настройте действующий ключ. Без него система показывает честную ошибку провайдера.
