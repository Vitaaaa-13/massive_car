# Безопасность и ограничения

Ключ GigaChat берётся из окружения и исключён из Git и Docker context. Внешнему API передаются фрагменты документов, поэтому реальные конфиденциальные данные нельзя загружать без отдельного разрешения и оценки защиты. Вход администратора отключён, пока не задан `DOCASSIST_ADMIN_PASSWORD_HASH`; пароль проверяется PBKDF2-HMAC и не хранится в БД. SQLite и файлы не опубликованы отдельными портами. Ролевая модель действует внутри Streamlit; для промышленной эксплуатации нужны внешняя аутентификация, журнал аудита, контроль доступа к отдельным документам и защита хранилища.
