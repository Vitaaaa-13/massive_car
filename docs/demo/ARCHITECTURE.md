# Архитектура

Streamlit (`app.py`) вызывает `docassist.py` для индексации, поиска, редакций, диалогов и GigaChat. `templates.py` заполняет копии оригинальных DOCX. SQLite хранит документы, редакции, фрагменты, FTS5-индекс и сообщения. Файлы лежат в `data/uploads/`. Docker Compose монтирует `data/`, поэтому состояние сохраняется между перезапусками.
