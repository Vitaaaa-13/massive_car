# Поиск и ответы

PDF разделяется на фрагменты с номером страницы и пункта. DOCX индексируется по абзацам и строкам таблиц, с заголовками колонок. В поиске участвуют только активные редакции. FTS5 отбирает кандидатов, после чего в GigaChat отправляются ограниченные по длине фрагменты. Ответ показывается, только если модель процитировала ID фрагментов из текущего поиска. Эта проверка подтверждает существование ссылки, но не доказывает корректность каждого вывода. При отсутствии источников и недоступности API система сообщает об этом. Семантический поиск пока не реализован.
